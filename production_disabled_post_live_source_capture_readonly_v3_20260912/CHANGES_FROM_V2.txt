P0 live_source_capture.py
-------------------------
v2 read_readonly() used os.open(path, os.O_RDONLY) only and
followed filesystem symlinks. A main.py symlink to a file
outside win5 still passed path.is_file() and leaked the target.

v3:
  - lstat: only regular files; symlink is explicit STOP
  - Linux open uses O_RDONLY|O_NOFOLLOW
  - fstat after open must still be a regular file
  - /proc/self/fd path must be under resolved WIN5_ROOT
  - that path's relative form must equal the expected rel
  - resolve/fd path outside WIN5_ROOT => STOP before payload
  - unlinked fd (" (deleted)") or post-open lstat/inode mismatch => STOP
  - any one of the three files failing omits tar/base64 entirely
