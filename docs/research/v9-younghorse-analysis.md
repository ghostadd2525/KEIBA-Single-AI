## 0. 要約（Verdict）

| 問い | 結論 |
|------|------|
| 若駒で Hit が落ちるか？ | **「若駒全般」ではない。落ちているのは主に 2歳新馬（初出走）** |
| 2歳戦だけ有意に効く特徴は？ | **`model_rank` / `honmei` の多重タイ（rank degeneracy）** |
| 騎手継続・乗り替わりは？ | サンプル小。若駒内では乗り替わり Hit 高・継続低だが **3歳未勝利寄り**で、2歳新馬固有ではない |
| 厩舎・父系・母父は？ | **本番コーパスに未露出（DATA GAP）** — 今回は検証不能 |

**最重要メカニズム（2歳新馬）**

- Strict Hit（一意トップピック）: **0 / 7（0%）**
- Soft Hit（勝者を raw `model_rank==1` 群に含む）: **4 / 7（57%）**
- Rank degeneracy（rank1 タイ ≥3 頭 or honmei ≥3）: **5 / 7（71%）**、平均タイ **4.43 頭**
- 同条件は **3歳未勝利・1勝クラス以上では 0%**（平均タイ 1.00）

→ 2歳新馬の「外れ」は、完全に的外れというより **本命群への収束失敗（ランク退化）** が支配的。

## 1. 目的・スコープ

### 目的

2歳戦・新馬・未勝利で Hit 率が低下する原因を、クラス別・Miss タクソノミ・追加クロスで切り分ける。

### 対象セグメント

1. 2歳新馬  
2. 2歳未勝利  
3. 3歳未勝利  
4. 1勝クラス以上（2勝/OP/特別・名称戦を含む）  
5. 重賞（G1–G3 表記）

### 比較指標（Research KPI）

| 指標 | 定義（本調査） |
|------|----------------|
| **Hit** | タイブレーク後の一意トップ（`model_rank`↑ → `win_prob`↓ → `horse_number`↑）== 勝ち馬 |
| **Purchase** | 本番に Delete 層 `purchase_eligible` が無いため **Hit と同値（proxy）** |
| **rank710** | Miss かつ unique `winner_rank` ∈ [7,10] |
| **rank46** | Miss かつ unique `winner_rank` ∈ [4,6] |
| **other_miss** | それ以外の Miss |

参考（Lab 正本）: `research/v3_lab/a01_accuracy.py` の `_classify_miss` / Purchase 定義。  
本番 `race_evaluations.miss_category`（`miss_top1|3|5`）とは語彙が異なる。

### 追加クロス

騎手 / 継続騎乗 / 乗り替わり / 厩舎 / 父系 / 母父 / 初出走 / 出走1戦 / 出走2戦

### コーパス

- `1勝`/`2勝`/`オープン`/特別・S・賞（G表記なし）→ 1勝クラス以上

|------|--------|------------|

### 統計上の注意

n=51・セグメント最小セルは n=6〜7。95% CI は広い。  
「有意」は本レポートでは **(a) 効果サイズが大きい (b) 他クラスで同パターンが消える (c) Soft vs Strict のギャップ** の三点で判定（厳密な仮説検定は未実施）。

3. 2歳新馬 Miss の大半は **rank46**（タイブレーク後に 4–6 位扱い）— raw では本命タイに入っているケースが多い（§4）。

### 3.2 Rank degeneracy（クラス特異）

| セグメント | n | degeneracy率 | 平均 rank1タイ | 平均 honmei数 | Soft Hit率 | Soft−Strict |
|------------|--:|-------------:|---------------:|--------------:|-----------:|------------:|

**これが「2歳戦だけ有意に効く」主特徴量（代理指標）である。**

### 5.2 継続騎乗 / 乗り替わり（若駒）

| レベル | n | Hit率 | other_miss率 | rank46率 |
|--------|--:|------:|-------------:|---------:|
| continued（継続） | 12 | 8.3% | 50.0% | 33.3% |
| changed（乗替） | 11 | **45.5%** | 18.2% | 9.1% |
| debut_no_prior | 7 | 0.0% | 28.6% | 71.4% |
| unknown | 2 | 0.0% | 0.0% | 50.0% |

解釈:

- 乗替 > 継続は **効果サイズ大だが n 小**。内訳はほぼ **3歳未勝利**（2歳新馬は全員 debut）。  
- **2歳新馬固有の特徴ではない。** 再現確認が必要。  
- 1勝以上でも継続 2/12 Hit・乗替 0/7 Hit と方向が逆 — 若駒限定の見かけの相関の可能性。

一部 `runners.jockey` が馬名＋DB文言混入しており、騎手クロスの精度は限定的。

## 7. 因果の仮説（コード変更なしの整理）

1. **情報欠落仮説（従来）**  
   過去走ゼロ → ペース・着順・騎手実績が薄い → Hit 低下。  
   → Soft Hit 57% は「完全な情報欠落」だけでは説明しきれない。

2. **ランク退化仮説（本調査の主仮説）**  
   2歳新馬で PE 出力が **複数頭に同一 `model_rank=1` / `mark=honmei`** を付け、  
   単一トップ選定が事実上ランダム化 → Strict Hit が潰れる。  
   3歳未勝利以降ではタイが消え、Soft≈Strict。

3. **購入側仮説**  
   Purchase は Hit proxy のため、本調査では分離できず。Challenge 単勝 Benchmark とは別レイヤ。
