## 0. Verdict

2歳新馬の Rank Degeneracy は再現された。

| 指標 | 値（n=7） |
|------|-----------|
| Strict Hit | **0 / 7（0%）** |
| Soft Hit | **4 / 7（57.1%）** |
| Rank Degeneracy（タイ≥3） | **5 / 7（71.4%）** |
| 平均タイ頭数（全新馬） | **4.43** |
| 平均タイ頭数（退化レースのみ） | **5.40** |
| Soft−Strict | **+57.1pt** |
| Perfect Resolver 上限（Strict 天井） | **57.1%**（Soft に一致） |

**決定的な内部所見:** タイ群内の `win_prob` は **全頭ビット同一**。  
→ 「同点のときに `win_prob` で切る」は **機能しない**（Score 隣接 Tie Break は無効）。

**対比（非新馬 46R）:** 平均タイ 1.17、タイ>1 はわずか 2R。退化は **2歳新馬にほぼ特異**。

**Tie Break 候補の現状:** 本コーパスでは **有効な Evidence を実証できた候補はゼロ**。  
大半は DATA GAP（未収集）か、収集済みでもタイ群内で値が潰れている。

→ 次ステップはスコア改変ではなく、**予測時点スナップショットの収集設計**（`docs/design/v91-tie-resolver.md`）。

---

## 1. 目的

AI Score を変えず、**同点（Rank Degeneracy）時だけ**使う Tie Resolver の有効 Evidence を探す。

対象:

- 2歳新馬
- 初出走（本コーパスでは新馬 ≡ 初出走）

---

## 2. 定義

| 用語 | 定義 |
|------|------|
| **Strict Hit** | 一意トップ（`model_rank` → `win_prob` → `horse_number`）== 勝ち馬 |
| **Soft Hit** | 勝ち馬 ∈ raw 最小 `model_rank` 群（honmei 群の方が大きければその和集合） |
| **Rank Degeneracy** | タイ群サイズ ≥ 3 |
| **平均タイ頭数** | 新馬レースのタイ群サイズ平均 |
| **Tie Resolver** | タイ群の中から 1 頭を選ぶ後段ルール。**スコア自体は変更しない** |
| **Oracle Ceiling** | Soft Hit 率 = 完璧 Resolver でも届く Strict 上限 |

### 5.2 win_prob 同一の意味

タイ群内で `win_prob` がビット一致するため:

- Score を使った Tie Break は **情報ゼロ**
- Degeneracy は「順位ラベルの衝突」だけでなく **スコア空間でも潰れている**
- Resolver は **外部 Evidence（市場・厩舎・血統・調教等）必須**

これは PE 改修を意味しない。Resolver はスコアに触れず、タイ集合上の選択問題に落とす。

## 6. Resolver の理論上限

| シナリオ | Strict Hit |
|----------|------------|
| 現状 | 0/7（0%） |
| Soft 内を完璧解決 | **4/7（57%）** |
| Soft 外 3R | Resolver では回収不能 |

したがって V9.1 の成功条件は:

1. Soft∧¬Strict の **4R 回収**を目指す  
2. Soft 外は別 Research（候補プール / 特徴欠落）

## 7. 候補の優先度（収集設計向け）

実証前の **仮説優先度**（可用性ギャップ × 初出走適合）:

| 優先 | 候補 | 理由 |
|:----:|------|------|
| P0 | **人気 / 単勝オッズ**（予測時点スナップショット） | 新馬で唯一広く使える市場情報。現状 DATA GAP が最大ボトルネック |
| P0 | **厩舎（調教師）** | parse 済み `_trainer` を CSV/DB に出すだけ（PE 非変更）。騎手×厩舎の土台 |
| P1 | **父系 / 母父** | 初出走で過去走が無いときの古典的事前情報 |
| P1 | **馬体重 / 追切 / 調教** | 新馬新聞の主情報。現状ゼロ |
| P2 | ゲート（枠） | 部分データありだが本サンプル精度0。弱仮説 |
| P2 | 斤量 | 新馬はほぼ均一の可能性。低期待 |
| — | ジョッキー継続 | **初出走では定義不能**（除外） |

## 8. 限界

1. n=7（週末2日）。統計的有意性は主張しない。  
2. 人気・オッズが空のため、有力候補を **棄却も採択もできない**。  
3. 枠・斤量の欠損が日によって異なる。  
4. Soft 外 3R は本チケットの範囲外。  

---

## 9. 結論（Research）

1. Rank Degeneracy は 2歳新馬で支配的（平均タイ 4.43、退化率 71%）。  
2. Soft Hit 57% vs Strict 0% → **同点解決の価値は大きい**（最大 +4R）。  
3. 既存バンドル内シグナル（`win_prob`・馬番）では **解決不能**。  
4. 指定 Tie Break 候補のほとんどは **Evidence 未収集**。  
5. 実装前に必要なのは PE 変更ではなく、**予測時点の外部特徴スナップショット + Tie Resolver 設計**（設計書へ）。
