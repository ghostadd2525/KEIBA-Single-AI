# Version 1.0 Freeze 宣言

**宣言日:** 2026-07-21  
**対象:** Production Baseline tag **`v1.0.0-stable`**（commit `08c7986`）  
**効力:** 即時・無期限（次の正式メジャー/マイナー製品タグで後継が明示されるまで）  
**関連:** [`v1.0-completion-report.md`](./v1.0-completion-report.md) · [`stable-baseline-v1.0.0.md`](./stable-baseline-v1.0.0.md)

---

## 1. 宣言文

Version 1.0（`v1.0.0-stable`）を **正式にフリーズ**する。

以後、本タグが指すコードおよび **製品として確定した挙動**は **変更禁止**とする。  
新機能・挙動変更・Flag 既定の変更は、**Version 1.1** または **`research/*`** でのみ行う。

---

## 2. 変更禁止の範囲（`v1.0.0-stable`）

以下を **`v1.0.0-stable` に対して行ってはならない**。

| 禁止 | 例 |
|------|-----|
| タグの移動・上書き | `git tag -f v1.0.0-stable` |
| 当該ツリーへの機能追加コミットを「1.0 本番」と称すること | main に載せた新機能を 1.0 としてデプロイ |
| 予想ロジックの製品既定変更 | RePick V2 Flag 既定 ON、Core の既定経路変更 |
| HOLD の独断解除 | Real KeibaNet 本番常時接続 |
| 破壊的 schema 変更を 1.0 名目で本番適用 | 1.0 専用として非互換 migration を押し込み |

**許可される例外（1.0 系 Hotfix のみ）:**

- 本番を止める **致命的欠陥**の最小修正  
- 手順: 修正は別コミット → 新タグ **`v1.0.1-stable`**（以降 `v1.0.x-stable`）を切る → Freeze 文書に追記  
- `v1.0.0-stable` タグ自体は **動かさない**

ドキュメント（`docs/ops/*`）の運用追記は Freeze 対象外だが、**1.0 の製品挙動を変える記述に勝手に書き換えない**（アーキテクチャ Snapshot / Completion の史実を改ざんしない）。

## 3. 開発の置き場（必須ルール）

| 種類 | 置き場 | 本番反映 |
|------|--------|----------|
| 製品の次期機能・改善 | **Version 1.1**（feature branch → PR → 検証 → 新タグ例 `v1.1.0`） | 1.1 リリース承認後のみ |
| 実験・研究・未採用ロジック | **`research/*`**（例: `research/repick-v2/`） | **載せない**。Flag ON 禁止が原則 |
| 運用手順・監視・月次 | `docs/ops/` | 手順として従う。コード挙動は変えない |
| 1.0 本番デプロイ | checkout **`v1.0.0-stable`**（または承認済み `v1.0.x-stable`） | Runbook 遵守（overlay / migrate / restart） |

```text
禁止:  v1.0.0-stable を直接改変して新機能を出す
許可:  research/* で試す →（合格後）Version 1.1 で製品化
許可:  運用 docs を更新する
許可:  致命不具合のみ v1.0.x-stable ホットフィックス
```

## 5. ブランチ / タグ運用

| オブジェクト | ルール |
|--------------|--------|
| `v1.0.0-stable` | **不変**。本番 rollback の第一候補 |
| `main` | 運用 docs や 1.1 向け作業が入りうる。**main tip ≠ 自動的に 1.0 本番** |
| 本番 EC2 / Pages | 意図した tag/SHA を明示してデプロイ。Runbook の Baseline を優先 |
| `research/*` | 製品契約・本番 Flag に影響させない |

---

## 6. 違反時

1. 本番を **Baseline tag に戻す**（Pages Rollback / EC2 `git checkout v1.0.0-stable` + overlay + restart）  
2. Flag / KeibaNet 設定を除去  
3. インシデントとして記録し、再発防止を 1.1 Backlog または運用ルールに追加
