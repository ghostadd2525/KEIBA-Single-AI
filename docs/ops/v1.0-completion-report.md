## 1. Version 1.0 の目的

Expect KEIBA AI を **招待制βとして本番到達可能な安定版**にし、以下を同時に満たすこと。

1. 利用者が一時IDからログインし、レース一覧・AI予想に到達できる  
2. Cloudflare Pages（GUI+BFF）と EC2 Prediction Core が Tunnel 経由で接続される  
3. Collector RC-1・運用機能（監視・結果自動化）の骨格を同梱する  
4. 予想ロジックの実験的変更（RePick V2 等）を **製品既定に載せない**  
5. 開発フェーズを終え、**運用フェーズ**（監視・Runbook・月次報告）へ移行する
