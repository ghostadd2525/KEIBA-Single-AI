# Version 8.5 — Research Governance

**Status:** Knowledge Base self-management  
**Depends:** Version8.4 Knowledge Base  
**Non-goals:** PE / CE / AI / Production 変更。KB を Production 判定に直結させない。

---

## Governance アーキテクチャ

```
Knowledge Base
      ↓
 Governance Pass（v8:governance / v8:fri）
   ├── Aging（active → stale → archived）
   ├── Revalidation（285R / baseline）
   ├── Knowledge Decay（Score 時間減衰）
   └── Duplicate Merge（統合候補）
      ↓
 governance-dashboard.json（Research Dashboard）
      ↓
 Research Metrics（Active率 / Stale率 / …）
```

Safety: **Research only** — Production 判定には使わない。

中核: `scripts/ops/v8/governance.mjs`  
サブエージェント: `.cursor/agents/research-governance.md`

---

## Aging

```json
{
  "pattern_id": "PAT-001",
  "created_week": "2026-W31",
  "last_used": "2026-W37",
  "usage_count": 8,
  "status": "active"
}
```

| 条件 | status |
|------|--------|
| 未使用 ≥ 8週 | `stale` |
| 未使用 ≥ 16週 | `archived` |

---

## Revalidation

Accept Pattern を約 6週ごとに最新 285R / baseline で再評価。  
改善なし / regression → `stale`。

---

## Knowledge Decay

```
score' = max(0.35, score × (1 − 0.008 × weeks_unused))
```

例: 0.92 × 26週未使用 ≈ **0.74**

---

## Duplicate Merge

同一 `root_cause`（+ 同 proposal ラベル）が複数 → `merge_candidates.json`

```
PAT-001 + PAT-014 → Merge Candidate
```

---

## Research Dashboard

`development/knowledge/governance-dashboard.json`

- Active / Stale / Archived Pattern 数
- Merge Candidate 数
- Average Knowledge Score
- Active率 / Stale率 / Archive率 / 平均寿命
