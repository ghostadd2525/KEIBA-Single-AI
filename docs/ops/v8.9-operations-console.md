# Version8.9 — Operations Console

**Status:** Implemented  
**Parent:** Version8.8.1 Publish Layer  
**URL:** `/ops`  
**Non-goals:** PE / CE / AI / ResultAutomation / Research Logic 変更禁止  
**Production auto-apply:** false  

---

## Boundary（維持）

```
Research → Approval → Deploy Note → Human Deploy
```

Approve = Deploy Note 作成のみ。Human Deploy は手動。

---

## 機能

| # | 機能 | 内容 |
|---|------|------|
| ① | Approval Center | Proposal / Version / Week / Decision / Created / Expire / Remaining / Status。Approve / Reject / Decision 詳細 |
| ② | History Center | Approval / Deploy / Research / Weekly Report / Boundary Audit / Incident。Version・Week・Status 検索 |
| ③ | Evidence Viewer | Validation / Canary / 285R / Decision / Knowledge / deploy-note / weekly-report へのリンク |
| ④ | Runner Timeline | Start → phases → Publish → Approval → Deploy Note → Completed（開始・終了・時間・PASS/FAIL/Skip） |
| ⑤ | Approval Timeout | expires_at / 残り日数。Timeout = Rejected + `reason=approval_timeout` + `auto=true` |
| ⑥ | Live Monitor | Pages / PI / AI / EC2 / RA / Research Scheduler — Health / Latency / Last Update / Status（Healthy / Pending / Failed / No Data） |
| ⑦ | Search | Version / Week / Proposal / Pattern / Decision / Status |
| ⑧ | JSON Viewer | View JSON（Publish JSON + API JSON） |
| ⑨ | Download | Weekly Report / Boundary / Deploy Note / Approval Queue / Knowledge / JSON |
| ⑩ | Audit | 表示 → API → Publish → Runner → Source |

## データ経路

```
v8:runner
  → publishOpsSnapshot
  → publishConsoleLayer (v8.9)
  → public/ops-data/*
  → Pages
  → /api/ops/console (+ history/timeline/evidence/search/monitor-live)
  → Operations Console UI
```
