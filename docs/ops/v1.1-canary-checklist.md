## Flag Canary 手順

1. `public/config/beta.json` / `config/beta.json` の `ui_features` を段階 ON  
2. 既定: `v11_loading_errors=true`、他 `false`（`v11_auto_maintenance` 含む）  
3. 推奨 Canary 順: mobile → home → races → race_detail → explain → confidence → collector_status → system_health → ops_dashboard → **auto_maintenance**  
4. 各段階で: ログイン → ホーム → 一覧 → 詳細、および **全 Flag OFF** での見た目回帰

### auto_maintenance Canary

1. Flag OFF のままデプロイ → 土日・平日とも現行差分なし  
2. ステージングで `v11_auto_maintenance: true` のみ ON  
3. **平日 JST**: `maintenance.html` 誘導、USER `/api/predictions` → 503 `OPS_CLOSED`、health/login/invite OK、ADMIN bypass  
4. **土日 JST**: 通常サイト、USER predictions 利用可  
5. **手動上書き**: 平日 + `ops_mode: "PUBLIC"` → 公開 / 土日 + `maintenance_mode: true` → CLOSED  
6. Flag を `false` に戻し即時ロールバック確認  

詳細: [`v1.1-auto-maintenance-design.md`](./v1.1-auto-maintenance-design.md)
