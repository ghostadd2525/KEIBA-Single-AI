## API

既存利用: `/api/predictions`, `/api/confidence/:id`, `/api/health`, bundle `explain` / `ai_confidence` / `fallback_reason`。  
加算: `GET /api/ops/public-status`（exempt）。  
`beta.json` に `ui_features` 追加のみ（後方互換）。

### Auto maintenance（要約）

- Flag `v11_auto_maintenance`（既定 false）  
- 手動 `ops_mode` / `maintenance_mode` 最優先  
- 既定 Provider: WeekendCalendarProvider（JST 土日公開）  
- 非開催日: `maintenance.html` + USER API CLOSED（ADMIN bypass）
