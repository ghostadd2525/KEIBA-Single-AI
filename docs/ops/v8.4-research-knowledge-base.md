# Version 8.4 — Research Knowledge Base

**Status:** Long-term Research asset store  
**Depends:** Version8.3 Analyzer Feedback  
**Non-goals:** PE / CE / AI Core / Production Evidence 変更。

---

## Knowledge Base アーキテクチャ

```
週次 Research（decide / canary / feedback）
        ↓
 Knowledge Sync（v8:knowledge）
        ↓
development/knowledge/
  root_causes.json
  proposals.json
  canary_results.json
  accepted_patterns.json   ← Pattern Library
  rejected_patterns.json   ← Reject Library
        ↓
 Ranking / Validation が KB を読む（weekly history を毎回読まない）
        ↓
 Similarity Search + Knowledge Score → Validation Score
```

| 成果物 | パス |
|--------|------|
| KB | `development/knowledge/*` |
| Timeline | `development/history/research_timeline.json` |
| Sync CLI | `scripts/ops/v8/knowledge-base.mjs` |

## Similarity Search

新 Proposal 前（Ranking / Validation）で判定:

- 同じ Proposal があるか
- 類似 Proposal があるか
- 過去 Reject 済みか
- 過去 Accept 済みか

---

## Knowledge Score

```
no data → 0.5
else    → 0.1 + 0.9 × (accepted / (accepted + rejected))
```

例: Accept 4 / Reject 1 → **0.82**

Validation:

```
Score = (Impact × Confidence × Coverage × (0.5 + 0.5·KS))
        / (Risk × (1 + Cost))
```
