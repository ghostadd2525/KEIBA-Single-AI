# Version 8.3 — Analyzer Feedback Loop

**Status:** Research Analyzer self-evaluation  
**Depends:** Version8.2 Proposal Validation  
**Non-goals:** PE / CE / AI Core 変更。Production Evidence の書換。急激な Confidence ジャンプ。

---

## Feedback アーキテクチャ

```
Analyzer / Validation 予測
        ↓
Canary + 285R + Friday Decision（実測 / Research proxy）
        ↓
Analyzer Feedback
   ├── Prediction Error
   ├── Root Cause Precision
   ├── Confidence Calibration（徐々に）
   └── Validation Calibration
        ↓
analyzer_report.json + Research Metrics
        ↓
次回 Analyzer Confidence に反映（Research のみ）
```

学習対象は **Research 成果物のみ**。`evidence/improvement` は触らない。

| 成果物 | パス |
|--------|------|
| Feedback run | `development/analysis/analyzer-feedback/` |
| Weekly report | `development/history/analyzer_report.json` |
| Precision | `development/history/root_cause_precision.json` |
| Confidence bias | `development/history/analyzer_calibration.json` |
| Validation cal | `development/history/validation_calibration.json` |

実行: `v8:fri` 内（decide の後）または `npm run v8:feedback`

---

## Root Cause Precision

```json
{
  "candidate_pool": {
    "proposals": 18,
    "accepted": 6,
    "successful": 5,
    "precision": 0.833
  }
}
```

- `accepted` = Validation Pass（Canary 入口）
- `successful` = 実 Hit 改善 > 0
- `precision` = successful / accepted

---

## Confidence Calibration

```
bias ← clamp(bias + 0.04 × (precision − 0.5), ±0.15)
confidence' ← clamp(confidence + bias, 0..1)
```

急変せず徐々に補正。次回 `analyzeMiss` で適用。

---

## Validation Calibration

```
Calibration Error = |ValidationScore − actual_improvement_01|
```

`validation_calibration.json` にサンプル蓄積、平均誤差を Metrics へ。
