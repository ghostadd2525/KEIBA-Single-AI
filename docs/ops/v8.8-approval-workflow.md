# Version8.8 — Approval Workflow

**Status:** Implemented  
**Baseline parent:** Version8.5.1  
**Non-goals:** PE / CE / AI / ResultAutomation / Production auto-apply

---

## Boundary（維持）

```
Accept → RC → Deploy Note → Human Deploy
```

Dashboard **Approve** は Deploy Note 生成まで。`production_auto_apply: false`。Human Deploy は手動。

---

## Queue 投入条件（すべて必須）

| 条件 | 判定 |
|------|------|
| `decision == "accept"` | `fri-decision/decision.json` |
| `promote_to_production == true` | 同上 |
| Validation == PASS | `tue-proposal/proposal-validation.json`（`summary.pass>0 && fail==0` または全 gate） |
| Canary == PASS | `wed-canary/ranked-run.json`（PASS/PASS_WITH_WARNING あり・FAIL なし） |
| 285R == PASS | `thu-baseline/report.json`（improvement/pass または `measured_delta_hit_at_1 > 0`） |

それ以外は **投入しない**。

投入時フィールド:

- `created_at`
- `expires_at` = `created_at + 7 days`
- `status: pending`

---

## Timeout（Runner 毎日 03:00 / run-day）

`npm run v8:runner` および `run-day.mjs` 開始時に Approval Queue を監査。

`pending` かつ `now > expires_at` →

| フィールド | 値 |
|------------|-----|
| `status` | `rejected` |
| `reason` | `approval_timeout` |
| `auto` | `true` |

→ Knowledge `development/knowledge/rejected_patterns.json` に記録（`knowledge-base.mjs` `appendApprovalRejectedPattern`）。
