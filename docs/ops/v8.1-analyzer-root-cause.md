# Version 8.1 — Analyzer / Root Cause 強化

**Status:** Research Analyzer quality upgrade  
**Depends:** Version8 Self-Improvement Cycle  
**Non-goals:** PE / CE / AI Core 変更。Production 中の改善実行。

---

## ① Analyzer アーキテクチャ

```
Miss Evidence (miss_top1|3|5)
        │
        ▼
 per-race scoreMissEvent()     ← multi family + scores + confidence
        │
        ▼
 aggregateScores()             ← corpus scores / frequency_pct
        │
        ▼
 computeImprovementPriority()  ← Impact × Frequency × Score → A/B/C
        │
        ├── pattern-detect (累積 4週)
        ├── proposal-ranking
        ├── canary-ranked (Priority順)
        └── research-metrics + weekly_history
```

| 層 | モジュール |
|----|------------|
| Score | `scripts/ops/v8/root-cause-score.mjs` |
| Analyzer 接続 | `scripts/ops/improvement/lib/analyzers.mjs` (`analyzeMiss`) |
| Pattern | `scripts/ops/v8/pattern-detect.mjs` |
| Ranking | `scripts/ops/v8/rank-proposals.mjs` |
| Canary順 | `scripts/ops/v8/canary-ranked.mjs` |
| History | `scripts/ops/v8/weekly-history.mjs` → `development/history/weekly_history.json` |
| Metrics | `scripts/ops/v8/research-metrics.mjs` |

## ② Root Cause Score

1 Miss → **複数** `root_cause_families`。

```json
{
  "race_id": "…",
  "root_cause_families": ["candidate_pool", "repick"],
  "scores": { "candidate_pool": 0.82, "repick": 0.41, "delete": 0.07 },
  "confidence": { "candidate_pool": 0.71, "repick": 0.38 }
}
```

集約キー（`development/analysis/miss/latest.json`）:

- `root_cause_scores` / `root_cause_confidence` / `root_cause_frequency_pct`
- `per_race[]`
- `improvement_priority[]`

## ⑤ Improvement Priority

`priority_score ≈ 0.5·score + 0.35·frequency + 0.15·impact·max(score,freq)`

| Band | 意味 |
|------|------|
| A | 最優先 Canary |
| B | 次点 |
| C | 低優先（全部試さない） |
