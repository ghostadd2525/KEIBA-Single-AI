# Version8.7 — ADMIN 運営ポータル（Operations Dashboard）

**目的:** ADMIN マイページを運営ポータルとし、一時ID発行と閲覧専用 Operations Dashboard（`/ops`）へ導線を整理する。

**非変更:** PE / Candidate Evaluation / AI / ResultAutomation / Research コアロジック、Production 自動適用。

## 導線

1. マイページ（`role=ADMIN` のみ）
   - **ADMIN 運営メニュー**
   - 一時ID発行（既存機能・挙動変更なし）
   - Operations Dashboard → `/ops`
2. 一般ユーザー（USER）には運営メニュー非表示、`/ops` アクセス不可

## `/ops` セクション（閲覧専用）

| Section | Cards |
|---------|--------|
| System | Pages / EC2 / PI / AI / ResultAutomation / Research Scheduler |
| Production | Prediction / Board / History / Challenge / Archive / Realtime / Maintenance |
| Research | Current Week / Current Phase / Next Run / Recovery / Decision |
| Knowledge | Knowledge Score / Accepted Patterns / Rejected Patterns / Governance |
| Deploy | Deploy Queue / Accept済み候補 / deploy-note（自動適用禁止） |
| Reports | Weekly Report / Baseline Health Check / Boundary Audit / Incident Report |

## 権限

- ページ・API: **role=ADMIN**（legacy `admin_user_ids` も許可）
- Dashboard は **read-only**
- Production 書き換えボタンなし
- `production_auto_apply: false` / deploy-note only

## 主要ファイル

| Path | Role |
|------|------|
| `public/mypage.html` | ADMIN 運営メニュー |
| `public/ops.html` | Dashboard UI |
| `public/assets/ops-portal-v87.js` | クライアント（閲覧専用） |
| `functions/api/ops/portal.js` | 集約 API（GET） |
| `functions/_lib/opsPortalAccess.js` | ADMIN 判定 |
| `public/ops-data/portal-snapshot.json` | 静的スナップショット（任意上書き） |
| `public/_redirects` | `/ops` → `ops.html` |

## API

```http
GET /api/ops/portal
Authorization: Bearer <access>
```

- 200: セクションカード集約
- 401: 未ログイン
- 403: ADMIN 以外

Live 補完（クライアント）: `/api/ops/research-scheduler`, `/api/ops/result-automation`, `/api/ops/v71-metrics`（いずれも表示のみ）。
