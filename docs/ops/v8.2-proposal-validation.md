# Version 8.2 — Proposal Validation

**Status:** Research Proposal quality gate  
**Depends:** Version8.1 Analyzer / Ranking  
**Non-goals:** PE / CE / AI Core 変更。Validation Pass = 本番適用ではない。

---

## Validation アーキテクチャ

```
Proposal Ranking (V8.1)
        ↓
 Proposal Validation (V8.2)
   Impact / Risk / Confidence / Coverage / Cost
        ↓
 Validation Score + Similar Reject 警告
        ↓
   ┌────┴────┐
 Pass      Fail
   ↓         ↓
 Canary   gate_blocked（試さない）
```

| モジュール | 役割 |
|------------|------|
| `proposal-validate.mjs` | 寸法算出・Score・Similar・Gate |
| `canary-ranked.mjs` | **Pass のみ** Canary へ |
| `weekly-history.mjs` | Weekly Knowledge 保存 |
| `research-metrics.mjs` | Pass/Reject/再発率など |

---

## Validation Score（提案式）

```
ValidationScore =
  (Impact × Confidence × Coverage)
  ／
  (Risk × (1 + Cost))
```

- 各寸法は **0..1**
- `Risk` に下限 `ε = 0.08`（ゼロ除算防止）
- **Gate 閾値:** `GATE_THRESHOLD = 0.12`（`--gate` で上書き可）

| 寸法 | 意味 | 主な入力 |
|------|------|----------|
| Expected Impact | 期待改善量 | Analyzer score × family impact weight |
| Risk | 悪化リスク | family 基底 + Similar Reject 加算 |
| Confidence | 推定信頼度 | `root_cause_confidence[family]` |
| Coverage | 影響レース割合 | `frequency_pct / 100` |
| Cost | 実装規模 | family ごとの blast radius |

---

## Proposal Gate

```
Proposal → Validation → Pass → Canary
                      → Fail → 記録のみ（Canary 不送）
```

Hard block 例:

- coverage も signal も不足
- 直近 Reject と同 family かつ Impact が弱い

---

## Similar Proposal 判定

Weekly History の過去 `decision=reject` と同 Root Cause を照合。

例メッセージ: `Similar to 2026-W30 Reject CandidatePool Threshold`

警告は Risk を上げる。強い類似 + 弱い Impact は hard block。
