# Version8.8.1 — Publish Layer

**Status:** Implemented  
**Baseline parent:** Version8.5.1 / Version8.8  
**Scope:** Ops Publish Layer only  

**Non-goals（変更禁止）:** PE / CE / AI / ResultAutomation / Research Logic / Decision / Canary / Validation / Knowledge mutation / Production auto-apply

---

## 目的

Research 成果物を Operations Dashboard へ公開する。  
Dashboard は `public/ops-data/portal-snapshot.json` を主読取とする。

```
v8:runner
  → Research 終了（既存）
  → Publish Snapshot（本レイヤ）
  → Dashboard
```

---

## Publish マップ

| 元 | 先 (`public/ops-data/`) |
|----|-------------------------|
| `development/knowledge/` | `knowledge.json` |
| `development/weekly/*/reports/` | `reports.json` |
| `development/scheduler/` | `research-scheduler.json` |
| `development/approvals/` | `approval-queue.json`（互換 `approvals.json`） |
| `development/weekly/*/sat-deploy/deploy-note.json` | `deploy.json` |
| 上記集約 | `portal-snapshot.json` |

---

## Scheduler 実値

`research-scheduler.json` / portal `research` に以下を実値で書く（固定ラベル禁止）:

| フィールド | 内容 |
|------------|------|
| Current Week | `week_id`（例: `2026-W30`） |
| Current Phase | `current_phase`（無ければ null → No Data） |
| Last Run | `last_run_at` ISO |
| Next Run | 次の 03:00 JST を `YYYY-MM-DDT03:00:00+09:00` で計算 |
| Recovery | `active` / `idle`（`recovery_active` 実値）。無ければ null → No Data |

禁止例: `毎日 03:00 JST` などの固定文言。

---

## Approval / Deploy

| 成果物 | 内容 |
|--------|------|
| `approval-queue.json` | Pending / Approved / Rejected / Timeout 件数 + items |
| `deploy.json` | deploy-note 集約。`production_auto_apply: false` |

境界: **Accept → RC → Deploy Note → Human Deploy**（維持）

---

## フォールバック

固定値は禁止。データが無い場合は **null** を publish し、API/UI は **No Data** / **Pending** のみ表示。

Next Run / Recovery も実値が無ければ No Data。

---

## Runner 配線

`npm run v8:runner` の `finalize()` で dry-run 以外の終了時に常に:

```text
publishOpsSnapshot({ now })
```

手動再 publish:

```bash
npm run v8:publish
```
