---

## 1. Merge 方針

| 項目 | 内容 |
|------|------|
| 方式 | GitHub PR: `feature/v1.1-ui-ops` → `main`（**squash または merge commit**、チーム慣例に従う） |
| 本番挙動 | merge 直後も **全 Canary Flag 既定 false**（`v11_loading_errors` のみ true）→ v1.0 同等パス維持 |
| タグ | merge 後すぐには `v1.0.0-stable` を動かさない。安定確認後に別途 `v1.1.0` を検討 |
| 自動デプロイ | Pages が `main` 追従なら、Flag OFF のまま本番 UI が載る想定。**auto_maintenance は false のまま** |
