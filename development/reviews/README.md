# reviews/

Human Review 記録。Canary 実行前に `status: "approved"` を設定する。

例: `IMP-20260719-miss-001.json`

```json
{
  "proposal_id": "IMP-20260719-miss-001",
  "status": "approved",
  "reviewed_by": "admin",
  "reviewed_at": "2026-07-20T12:00:00.000Z",
  "notes": "Proceed to Canary"
}
```
