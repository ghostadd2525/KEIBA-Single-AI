# development/weekly — Version8 週次履歴

ISO 週 (`YYYY-Www`, JST) 単位で Research 成果を残す。

- Production Evidence は書かない（`evidence/improvement/` が正本）
- 土日は Research 実行禁止（`scripts/ops/v8/calendar.mjs`）
- `fri-decision/decision.json` の `no_improvement` / `reject` も成功履歴
