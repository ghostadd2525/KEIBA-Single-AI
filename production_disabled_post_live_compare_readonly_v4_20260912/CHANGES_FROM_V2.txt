P0-1
----
v2 treated systemctl show failure as NOTE only, so COMPARE_RESULT
could still be GO / exit 0 without systemd evidence.

v3 adds these EVIDENCE_GAPS (COMPARE_RESULT=STOP, exit != 0):
  systemd_show_failed
  systemd_unit_not_loaded
  systemd_execstart_absent
  systemd_working_directory_absent
  effective_env_unverified

LoadState is requested from systemctl show.
LoadState not-found / error / bad-setting => systemd_unit_not_loaded.

effective_env_unverified fires when ActiveState=active and
MainPID/process environ cannot be read.

P0-2
----
v2 used a secret-name denylist. Unlisted flags, URLs, and
KEY=VALUE leaked:
  --dsn postgres://user:supersecret@example/db
  --authorization BearerSecretValue
  DATABASE_URL=postgres://user:supersecret@example/db

v3 prints ExecStart via allowlist only:
  SYSTEMD_EXECSTART_PATH = executable path only
  argv = executable, -m / --module, a safe module name,
         and an explicit boolean-flag allowlist
  flag values, positionals, and KEY=VALUE are [REDACTED]
  URL / DSN / userinfo / Bearer / credential forms are hidden
  unknown values are [REDACTED]
  Environment raw values are still unpublished
