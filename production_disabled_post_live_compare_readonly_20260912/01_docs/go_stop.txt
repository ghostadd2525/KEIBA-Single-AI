GO / STOP for this step only
============================

This step is evidence collection. It never approves a deploy.

GO  (COMPARE_RESULT=GO)
-----------------------
All of the following are true:
  - WIN5_ROOT found (app/main.py exists)
  - deploy_files hashes recorded (ABSENT is a valid record)
  - main.py class recorded
  - systemd ExecStart / unit recorded
  - PREDICTION_RUNS_ENABLED and EXPECT_AI_ALLOW_MIGRATION_022
    classified as UNSET/ZERO/ONE/OTHER (not crashed)
  - sqlite opened read-only and 022 / 4 columns / index recorded

Owner action on GO:
  Return the full stdout transcript.
  Do not deploy. Do not create an APPLY pack.
  PRODUCTION_CODE_DEPLOY_ALLOWED stays NO
  OWNER_DEPLOY_APPROVED stays NO

STOP  (COMPARE_RESULT=STOP)
---------------------------
Any of:
  - win5_root_not_found
  - db_file_absent
  - db_readonly_open_failed
  - db_readonly_query_failed

Owner action on STOP:
  Do not guess paths. Do not write files to "fix" the probe.
  Return the transcript. Re-run only after the host can be
  read (correct user / unit / db path). Still no deploy.

HARD STOP before any later deploy pack
--------------------------------------
Even if COMPARE_RESULT=GO, do not start a Production code
deploy pack while any of these appear as STOP_REASON:

  - PREDICTION_RUNS_ENABLED_is_ONE
  - EXPECT_AI_ALLOW_MIGRATION_022_is_ONE
  - schema_022_missing
  - missing_col_idempotency_key
    / persist_source / input_snapshot_hash
    / prediction_semantic_hash
  - idempotency_index_not_ok
  - active_019_persist_sql_present
  - live_main_py_imports_runs_before_disabled_gate

Later main.py rule (not a compare STOP)
---------------------------------------
  MATCH_BASE      -> later deploy may use the v4 unified main.py
                    hunk-or-file against origin/main
  MATCH_CANDIDATE -> POST hunk already present; do not overwrite
                    main.py unless a new review says so
  DIVERGENT       -> hunk only; never replace live main.py wholesale

This pack does not authorize that later deploy.
