What this does
--------------
On the Production SSH host, paste OWNER_PASTE_COMMAND_BLOCK.sh
into bash. The script:

  1. Discovers win5 via read-only `systemctl show expect-ai.service`
     (-p Id, FragmentPath, WorkingDirectory, ExecStart, LoadState only).
     Never requests Environment or EnvironmentFiles.
  2. Opens exactly three files with os.O_RDONLY:
       app/main.py
       app/data/repository/__init__.py
       app/core/feature_loader_bridge.py
  3. Prints resolved path, size, SHA256 for each.
  4. Builds tar.gz in memory (those three members only).
  5. Prints the archive as base64 between
       === TAR_BASE64_BEGIN ===
       === TAR_BASE64_END ===
  6. Prints CAPTURE_RESULT=GO|STOP

What this does not do
---------------------
  - create or change any Production file
  - SCP upload
  - dump env values
  - open sqlite / read DB rows
  - collect race_id values
  - print ExecStart or Environment
  - run git pull / checkout / reset / merge
  - deploy, APPLY, restart, migrate, POST
